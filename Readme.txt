FF14 Retainer Market Scout 使い方
================================

このアプリは、FF14のリテイナーベンチャーで「今なにを取ってくると売れそうか」を見るためのツールです。

Universalisのマーケット情報を使って、園芸・採掘・戦闘リテイナーが取ってこられる素材を、売れやすさと価格から並べます。


まず見るところ
--------------

起動したら、画面は大きく3つに分かれています。

・園芸 Top 3
・採掘 Top 3
・戦闘 Top 3

それぞれの上に出ている大きなカードが、そのリテイナーで特におすすめの候補です。
下のリストには、候補素材がスコア順に並びます。


基本の使い方
------------

1. データセンターを選びます。
   例: Mana

2. ワールドを選びます。
   例: Titan

3. 直近日数を確認します。
   初期値は3日です。
   これは「直近何日間の売れ行きを見るか」という意味です。

4. ExpressVPNを使わない場合は、
   「更新前にExpressVPN MCPで接続する」のチェックをオフにしてください。

5. 更新ボタンを押します。

6. 取得が終わると、園芸・採掘・戦闘ごとのおすすめ素材が表示されます。

更新中はボタンが「中止」に変わります。
途中で止めたいときは「中止」を押してください。


スコアとは？
------------

Scoreは「今リテイナーに取りに行かせる価値がどれくらいありそうか」を表す目安です。

ざっくり言うと、次のような素材ほどスコアが高くなります。

・直近X日間で実際に売れた単価が高い
・リテイナーが一度に多く取ってこられる
・直近でよく売れている
・売れた件数が多い
・売れた個数が多い
・最近売れている
・99個単位でよく売れている

逆に、価格が高くても最近売れていない素材や、たまたま1回だけ高く売れた素材は低めになります。

Scoreはあくまで目安です。
実際に出品するときは、最安価格や出品数も見て判断してください。
最安価格は表示用の参考値で、Scoreの計算には使っていません。


リストの見方
------------

Score:
  おすすめ度です。高いほど上に来ます。

素材:
  アイテム名です。

Lv:
  リテイナーベンチャーのレベルです。

数:
  リテイナーが1回で取ってくる推定個数です。

最安:
  現在のマーケットの最安値です。
  これは表示用の参考値です。ランキングのScoreには使っていません。

販:
  直近X日間に売れた回数です。
  Xは画面上の「直近日数」です。

売個:
  直近X日間に売れた合計個数です。

印:
  99個単位でよく売れている素材に色付きの丸印が出ます。


99個売りの印
------------

素材によっては、1個ずつではなく99個まとめて買われるものがあります。
このアプリでは、そういう素材に印をつけています。

金色:
  直近X日間の販売件数のうち、99個売りが30%以上

銀色:
  直近X日間の販売件数のうち、99個売りが20%以上

銅色:
  直近X日間の販売件数のうち、99個売りが10%以上

印がある素材は、まとめ売り需要がありそうな素材です。
ただし、必ず99個で売れるという意味ではありません。


直近日数について
----------------

直近日数は、マーケットの売れ行きを何日分見るかの設定です。

おすすめは3日です。
最近の売れ行きを重視したい場合は短めにします。
もう少し安定した傾向を見たい場合は7日などにします。

短くすると、今売れている素材が上がりやすくなります。
長くすると、一時的な売れ方に左右されにくくなります。


ExpressVPNについて
------------------

このアプリには、更新前にExpressVPN MCPへ接続するオプションがあります。

ExpressVPNを使っていない場合、またはMCP機能を使わない場合は、
「更新前にExpressVPN MCPで接続する」のチェックをオフにしてください。

チェックがオンのままだと、ExpressVPN MCPに接続できない環境では更新に失敗します。

ExpressVPNを使う場合は、次の点を確認してください。

・ExpressVPNのベータ版デスクトップアプリを使っている
・ExpressVPN側でMCPサーバー機能が有効になっている
・MCP/接続先が次のような形式になっている

  http://127.0.0.1:20090/mcp|smart

「|」の右側は接続先です。
smartはExpressVPN側のおまかせ接続です。


アイテム名のコピー
------------------

カードやリストにあるコピーボタンを押すと、アイテム名をコピーできます。

コピーできた場合は、画面下のステータスバーに「コピーしました」と表示されます。


Universalisで見る
-----------------

リストでアイテムを選んで「Universalisで見る」を押すと、そのアイテムのUniversalisページを開けます。

マーケットの細かい状況を確認したいときに使ってください。


画像について
------------

アイテム画像はXIVAPIから取得して、パソコン内にキャッシュします。

一度取得した画像は、次回以降なるべく保存済みのものを使います。


うまく動かないとき
------------------

更新でエラーになる場合:
  ExpressVPNを使っていないなら、ExpressVPNのチェックをオフにしてください。
  ワールドやデータセンターが選ばれているか確認してください。
  少し時間を置いてからもう一度更新してみてください。

スコアが0になる場合:
  直近日数内に売れていない可能性があります。
  直近日数を7日などに広げると表示されることがあります。

画像が出ない場合:
  XIVAPIから画像を取得できなかった可能性があります。
  ランキング自体には大きな影響はありません。


注意
----

このアプリの結果は、Universalisに集まっているマーケット情報をもとにしています。

Universalisの情報はプレイヤー投稿ベースなので、実際のゲーム内マーケットと少しズレることがあります。

最終的に出品する前には、ゲーム内マーケットボードやUniversalisのページも確認するのがおすすめです。
